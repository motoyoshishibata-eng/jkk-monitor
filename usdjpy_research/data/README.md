# data/ に置くファイル

ここに置いた CSV は Git に入りません（`.gitignore` 済み）。容量が大きいのと、
ブローカー配信データを公開リポジトリに置かないためです。

## 必須（Phase 0〜3・6）

### `USDJPY_M1.csv` — ファイネストMT5 のバーデータ

1. ツール → オプション → チャート → 「ヒストリー内の最大バー数」を無制限に
2. 表示 → 銘柄（Ctrl+U）→ USDJPY → 「バー」タブ
3. 時間足 **M1**、期間を全期間 → 「エクスポート」
4. `USDJPY_M1.csv` としてこのフォルダに保存

Phase 2・3 は分単位の約定を見るので **M1 が必須** です。
M5 / H1 も出しておくと Phase 1・6 が速く回りますが、無くても動きます。

読める形式（区切り文字とヘッダは自動判別します）:

```
<DATE>	<TIME>	<OPEN>	<HIGH>	<LOW>	<CLOSE>	<TICKVOL>	<VOL>	<SPREAD>
2024.01.02	00:00:00	141.041	141.055	141.035	141.048	53	0	14
```

`<SPREAD>` 列が **0 ばかりだと Phase 0-3 のコスト実測ができません**。
その場合は `config/spread_finest.csv` を手で作ってください（作り方は
Phase 0-3 のレポート末尾に出ます）。

## Phase 4 用

### `click365_usdjpy.csv` — くりっく365 の建玉

くりっく365（東京金融取引所）公式サイトのヒストリカルデータから作ります。
2005年7月1日の上場以降が無料で取れます。

```
date,long_oi,short_oi
2005-07-01,12345,23456
```

### `cftc_jpy.csv` — CFTC建玉（任意だが強く推奨）

新規性の確認（CFTCと同じ情報しか持っていないなら打ち切り）に使います。

```
date,net_noncommercial
2005-07-05,-12345
```

## Phase 5 用

いずれも `date,close` の2列。債券は **total return 指数** を使ってください
（price only だとクーポンが落ちてヘッジ必要額の推定がずれます）。

- `idx_us_equity.csv` — S&P500
- `idx_jp_equity.csv` — TOPIX
- `idx_us_bond.csv`   — 米国債インデックス
- `idx_jp_bond.csv`   — 日本国債インデックス
